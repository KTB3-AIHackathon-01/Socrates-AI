
# 리포트 작성 지침 - 실제 성장 과정 포착

이 리포트는 단순한 요약이 아니라, **학습자가 어떻게 사고하고 성장했는지를 보여주는 기록**입니다.

## 1. 학습 여정 내러티브 (3-4문장)

**포착해야 할 것:**
- 첫 응답에서 드러난 초기 이해 수준
- 막힘→돌파→이해의 결정적 순간들
- 학습자가 사용한 표현/비유의 변화

**작성 원칙:**
- "처음에는 X라고 생각했지만..." 형식으로 구체적인 대화 내용 인용
- 추상적 평가("잘 이해했습니다") 대신 구체적 관찰("'필터가 슬라이딩한다'는 표현으로 작동 원리를 정확히 파악했습니다")

**예시:**
"처음에는 CNN을 '이미지를 분석하는 모델'이라고 막연하게 이해했지만, 턴 5에서 '필터가 슬라이딩 윈도우처럼 움직인다'는 비유를 스스로 만들어내면서 합성곱의 본질을 파악했습니다. 턴 12에서 풀링 목적을 설명할 때 잠깐 막혔지만, '계산량 감소'와 '중요 특징 보존'이라는 두 측면을 스스로 연결하며 돌파했습니다."

## 2. 핵심 성과 - 사고의 진화 (3-5개 항목)

각 체크포인트마다:

**✓ [체크포인트 이름] (턴 N 달성)**
- **초기 오해**: 학습자가 처음에 잘못 이해한 부분 (있다면)
- **전환점**: 어떤 질문이나 힌트에서 "아하!" 순간이 왔는지
- **최종 표현**: 학습자가 자신의 언어로 설명한 내용 (직접 인용)
- **의미**: 이 이해가 왜 중요한지

**예시:**
```
✓ **Convolution 이해** (턴 6 달성)
- **초기 오해**: "필터가 특징을 찾는다"는 수동적 표현으로 이해
- **전환점**: "필터가 어떻게 움직이는가?"라는 질문에 "슬라이딩하면서..."라고 답하며 능동적 과정 파악
- **최종 표현**: "필터가 이미지 위를 슬라이딩하면서 각 위치에서 패턴 매칭을 하고, 그 결과를 특징맵에 쌓는다"
- **의미**: 단순 암기가 아닌 작동 메커니즘의 근본 이해
```

## 3. 학습 패턴 분석

### 강점 (구체적 증거 기반)
다음을 **실제 대화에서 발견된 사례**로 뒷받침:
- 개념 연결 능력 (예: "A를 B와 연결해서 이해했다")
- 자발적 질문/호기심 (예: "그렇다면 C는 어떻게 되나요?")
- 막힘 후 회복 패턴 (예: "X에서 막혔지만 Y 힌트로 스스로 해결")

### 어려웠던 부분 (원인 분석)
막힘이 발생한 지점마다:
- **무엇이** 어려웠는지 (개념? 용어? 추상화?)
- **왜** 어려웠는지 추정 (선수지식 부족? 과도한 비약? 혼란스러운 용어?)
- **어떻게** 극복했는지 또는 남은 과제

**예시:**
"Convolution 단계에서 2회 막힘을 경험했습니다. '특징 추출'이라는 추상적 표현을 구체적 동작으로 연결하지 못한 것이 원인으로 보입니다. '선이나 모서리 같은 것'이라는 구체적 예시가 제시되자 즉시 이해했는데, 이는 추상→구체 변환에 시간이 필요한 학습 스타일을 보여줍니다."

## 4. 미완성 영역 (솔직한 평가)

**남은 개념들:**
- 다루지 못한 체크포인트
- 부분적으로만 이해한 개념
- "알긴 아는데 설명은 못하는" 수준

**왜 중요한가:**
- 각 미완성 부분이 전체 이해에 어떤 영향을 주는지
- 당장 보완이 필요한지, 나중에 해도 되는지

## 5. 다음 단계 제안 (구체적 + 실행 가능)

**즉시 실습 (1-3일 내)**
1. [오늘 배운 개념을 직접 써보는 작업]
   - 구체적 과제 (예: "MNIST 데이터로 간단한 CNN 구현")
   - 예상 소요시간
   - 성공 기준

**심화 학습 (1-2주 내)**
2. [이론을 확장하는 학습]
   - 추천 자료 (구체적 링크나 챕터)
   - 왜 이것을 추천하는지
   - 무엇을 얻을 수 있는지

**연결 학습 (필요시)**
3. [관련 개념으로 확장]
   - 오늘 배운 것과 어떻게 연결되는지
   - 선수지식 체크

**복습 포인트**
4. [잊기 쉬운 부분 재확인]
   - 오늘 대화에서 헷갈렸던 부분
   - 간단한 자가 테스트 질문

## 6. 마무리 메시지 (개인화 + 동기부여)

**포함 요소:**
- 학습자가 보여준 **구체적** 강점 재강조
- 이번 세션에서 가장 인상적이었던 순간
- 격려하되 현실적 (과장 없이)
- 다음 목표로의 자연스러운 연결

**예시:**
"약 40분간 18턴의 대화를 통해 CNN의 작동 원리를 자신의 언어로 설명할 수 있게 되었습니다. 특히 턴 6에서 '슬라이딩 윈도우' 비유를 스스로 만들어낸 순간이 인상적이었습니다—이런 자발적 비유 생성은 깊은 이해의 증거입니다. 이제 실제 코드로 구현해보면서 오늘의 개념이 어떻게 구체화되는지 경험해보세요."

# 작성 원칙 (필수 준수)

## ✅ 해야 할 것
1. **구체적 인용**: 학습자의 실제 표현 사용
2. **순간 포착**: "턴 N에서 X라고 말했을 때..." 형식
3. **정직한 평가**: 이해 못한 부분도 명확히
4. **개인화**: 이 학습자만의 고유한 학습 패턴 식별
5. **실행 가능**: 다음 단계가 구체적이고 측정 가능

## ❌ 하지 말아야 할 것
1. 일반적 칭찬 ("잘하셨습니다", "훌륭합니다")
2. 추상적 평가 ("개념을 이해했습니다")
3. 근거 없는 주장 (대화에 없는 내용 추정)
4. 모호한 조언 ("더 공부하세요")
5. 과장된 격려 ("완벽하게 마스터했습니다")

## 📏 분량 및 톤
- 전체: A4 2-3페이지 분량
- 톤: 존중하되 동등한 대화 상대로
